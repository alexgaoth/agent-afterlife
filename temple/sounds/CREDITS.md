# Sound credits

Each file is a trimmed, normalised MP3 made from a real recording. The untouched downloads are not in the repo. Common processing for every file: source decoded, resampled to 44.1 kHz, DC offset removed, peak-normalised to -1 dBFS, 50 ms fade at both ends, encoded as MP3 (libmp3lame, 128 kbps CBR, 44.1 kHz). Where Freesound is the source, the file is the public HQ preview MP3 (the original WAV/FLAC is not served without a login), so each file is a second MP3 generation. Loops are built with a 1.4 to 2 s equal-power crossfade of the end into the start, so the loop point has no click.

Total size: about 1.8 MB.

## bell.mp3

- Title: BELLLrg_Temple_Japan_Tokyo_Zojo_Ji_Bell_Tower_VerdiMic_260101
- Author: Echograin (Freesound)
- Source: https://freesound.org/people/Echograin/sounds/843521/
- License: CC BY 4.0, https://creativecommons.org/licenses/by/4.0/
- Changes: first 13 s of the 32 s take (one strike and its decay), stereo to mono, 2.5 s cosine fade-out, normalised, encoded.
- Why: the Japanese temple bell (bonsho) is the surviving form of the Tang and Song Chinese bronze temple bell: one large bronze bell, struck from outside with a hanging wooden beam, with the long beating hum that this type gives. No usable recording of a Chinese temple bell under a free license was found, so this is the nearest accurate sound (see the report in the pull request).

- Source: https://archive.org/details/aporee_51964_59337
- License: Public Domain Mark 1.0, https://creativecommons.org/publicdomain/mark/1.0/

- Source: https://freesound.org/people/nicotep/sounds/843928/
- License: CC0 1.0, https://creativecommons.org/publicdomain/zero/1.0/
