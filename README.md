# Published fleet data

`afterlife.json` follows `schema/afterlife.schema.json` on `main`. It is written by a private exporter: agents carry VC names from the current list; auto-titled sessions are Unnamed. The graveyard and wumiao sites read it from this branch.

`afterlife-zh.json` is the same fleet with every name mapped to a beloved Chinese figure who has died (no politicians), for a Chinese-language view: `?data=https://raw.githubusercontent.com/alexgaoth/agent-afterlife/data/afterlife-zh.json`. The mapping is fixed; new names get the next figure.
